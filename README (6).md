## 🚀 About the Project

<div align="center">

```
 ☀️  ⚫  🟡  🌍  🔴  🟠  🪐  🔵  🌀
Sun Mercury Venus Earth Mars Jupiter Saturn Uranus Neptune
```

</div>

**Space Explorer** is a **visually stunning**, **fully interactive** solar system web application built from scratch with **React 18** and **TypeScript**. This is not just another planets website — it's an immersive cosmic experience designed to make learning about space fun, beautiful, and unforgettable.

### 💡 Why I Built This

Space has always been fascinating. This project was born from a desire to combine a love for astronomy with the art of frontend development — creating something that feels alive, animated, and awe-inspiring. Every star twinkles, every planet floats, every orbit spins — just like the real universe. 🌠

### 🎯 What Makes It Special

- 🌟 **Live animated starfield** with 200+ twinkling stars using HTML5 Canvas
- 🌀 **Real-time orbit animations** showing Earth, Mars, and Jupiter orbiting the Sun
- 🎨 **Deep space color palette** with neon glows and cosmic gradients
- 📊 **Rich planet data** — every planet with real scientific facts
- ⚡ **Blazing fast** — optimized React components, no heavy libraries

| 📋 **React DOM** | 18.2.0 | DOM Rendering | Concurrent mode, automatic batching |

### 🧠 Key Technical Decisions

```typescript
// TypeScript interface for type-safe planet data
export interface Planet {
  id: number;
  name: string;
  emoji: string;
  type: 'Terrestrial' | 'Gas Giant' | 'Ice Giant';
  distanceFromSun: string;
  diameter: string;
  moons: number;
  description: string;
  color: string;
  funFact: string;
  temperature: string;
}
```

```javascript
// Canvas starfield — 200 stars, twinkling with sine wave opacity
const animate = () => {
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  stars.forEach(star => {
    const twinkle = Math.sin(frame * star.speed * 0.05) * 0.4 + 0.6;
    ctx.fillStyle = `rgba(255, 255, 255, ${star.opacity * twinkle})`;
    ctx.fill();
  });
  requestAnimationFrame(animate);
};
```

### 📊 Component Architecture

```
<App>                          ← State management, planet data, routing
 ├── <StarField />             ← Canvas background (fixed, full screen)
 ├── <Navbar />                ← Fixed top navigation
 ├── <Hero />                  ← Landing hero with orbit animation
 ├── <PlanetCard /> × 8       ← Grid of planet cards with filter
 └── <Footer />                ← Bottom section

<PlanetDetail>                 ← Separate full-page view (conditional render)
 ├── <StarField />             ← Reused starfield background
 └── Stats Grid                ← 4-column stats: diameter, distance, moons, temp
```

## ⚡ Getting Started

### 📋 Prerequisites

Make sure you have the following installed on your system:

| Tool | Version | Download |
|:----:|:-------:|:--------:|
| Node.js | v16+ | [nodejs.org](https://nodejs.org/) |
| npm | v8+ | Comes with Node.js |
| Git | Latest | [git-scm.com](https://git-scm.com/) |

Check your versions:
```bash
node --version    # Should be v16.0.0 or higher
npm --version     # Should be v8.0.0 or higher
git --version     # Any recent version
```

### 🚀 Installation & Setup

```bash
# Step 1: Clone the repository
git clone https://github.com/ritu25mib10064-pixel/space-explorer.git

# Step 2: Navigate into the project directory
cd space-explorer

# Step 3: Install all dependencies
npm install

# Step 4: Start the development server
npm start
```

✅ The app will automatically open at **[http://localhost:3000](http://localhost:3000)**

### 🏗️ Available Scripts

| Command | Description |
|:-------:|:------------|
| `npm start` | Runs the app in development mode with hot reload |
| `npm run build` | Creates an optimized production build in `/build` |
| `npm test` | Launches the test runner in interactive watch mode |
| `npm run eject` | Ejects from Create React App (⚠️ irreversible!) |

### 📦 Build for Production

```bash
# Create optimized production build
npm run build

# The build folder is ready to deploy!
# You can serve it with any static hosting service:
# - Vercel, Netlify, GitHub Pages, Firebase Hosting
```

### 🌐 Deploy to GitHub Pages

```bash
# Install gh-pages
npm install --save-dev gh-pages

# Add to package.json scripts:
# "predeploy": "npm run build",
# "deploy": "gh-pages -d build"

# Deploy!
npm run deploy
```

## 🎮 How to Use

```
1. 🏠 Open the app at localhost:3000
        ↓
2. 🌠 Enjoy the animated starfield and orbiting planets in the hero
        ↓
3. 🔽 Scroll down to see the planet grid
        ↓
4. 🎯 Use the filter buttons to view by type:
       [All] [Terrestrial] [Gas Giant] [Ice Giant]
        ↓
5. 🖱️ Click on any planet card to open its detail view
        ↓
6. 🔭 View detailed stats: diameter, distance, moons, temperature
        ↓
7. 💡 Read the fun fact for each planet
        ↓
8. ← Click "Back to Solar System" to return to the grid
```
