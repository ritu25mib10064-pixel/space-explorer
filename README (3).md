## 🌟 Features

- 🪐 **All 8 Planets** — Interactive cards for every planet in our solar system
- 🔍 **Detailed View** — Click any planet to see in-depth stats and fun facts
- 🎨 **Animated Starfield** — Twinkling stars canvas background for an immersive feel
- 🌀 **Live Orbit Animation** — Spinning orbital rings in the hero section
- 🔎 **Filter by Type** — Filter planets by Terrestrial, Gas Giant, or Ice Giant
- 📱 **Fully Responsive** — Looks great on mobile, tablet, and desktop
- ⚡ **Fast & Lightweight** — No heavy libraries, pure React + CSS animations

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:
- [Node.js](https://nodejs.org/) (v16 or higher)
- npm (comes with Node.js)

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/Khushi-Roy-123/space-explorer.git

# 2. Navigate to project directory
cd space-explorer

# 3. Install dependencies
npm install

# 4. Start the development server
npm start
```

The app will open at **http://localhost:3000** 🎉

### Build for Production

```bash
npm run build
```

This creates an optimized production build in the `/build` folder.
